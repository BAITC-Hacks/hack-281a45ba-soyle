# Как запустить Soyle

## Первый запуск в Windows

1. Установите **Node.js 22.12+ из ветки 22 либо версии 24+**, если он ещё не установлен. Проект проверен на версии 24.11.1. После установки заново откройте PowerShell.
2. Проверьте, что Node.js и npm доступны:

```powershell
node --version
npm.cmd --version
```

3. Перейдите в папку проекта, установите зависимости и запустите приложение:

```powershell
cd C:\Users\RESTART_OZEN\Hackathon
npm.cmd install
npm.cmd run dev
```

Установка зависимостей требует интернета и выполняется один раз. Дождитесь адреса сервера в терминале.

4. Откройте в браузере **http://127.0.0.1:5173**. Если порт занят, Vite выберет другой — используйте адрес, который появился в терминале.

Оставьте окно PowerShell открытым, пока работаете с Soyle. Чтобы остановить сервер, нажмите **Ctrl+C** в этом окне.

## Следующие запуски

Повторная установка зависимостей не нужна:

```powershell
cd C:\Users\RESTART_OZEN\Hackathon
npm.cmd run dev
```

Если PowerShell сообщает, что запуск `npm.ps1` запрещён, используйте именно `npm.cmd`, как в примерах. Менять политику выполнения PowerShell не требуется.

## Работа с демоверсией

Переключайте роли «Бизнес» и «Студент» в интерфейсе. Вопросы и поля карточки снабжены примерами ответов: адаптируйте их под свою ситуацию. Инструкция по сценарию находится в разделе «Как это работает» и в [docs/demo.md](docs/demo.md).

Одна команда запускает интерфейс и локальный backend: отдельный процесс не нужен. По умолчанию AI работает в явно обозначенном mock-режиме без ключей и `.env`. Оба этапа AI и расчет рейтинга выполняются через API. Настройка настоящего OpenAI через серверный `.env` описана в [README.md](README.md); без ключа используйте `AI_MODE=mock`.

Задачи и отклики сохраняются в этом браузере для текущего адреса сайта; на другом устройстве они не появятся автоматически. Используйте один адрес и порт, чтобы продолжать работу с сохранёнными данными.

Редактируйте данные в одной вкладке. Перед защитой откройте «Как это работает» → «Скачать копию». Для переноса данных используйте «Загрузить копию» и подтвердите замену. Набранная, но ещё не сохранённая или не отправленная форма в общую копию не входит.

При предупреждении об ошибке сохранения скачайте текущие данные или нажмите «Повторить сохранение» после устранения причины; до этого не закрывайте страницу. При конфликте вкладок сначала скачайте свою версию, затем нажмите «Загрузить обновления». Подробности и ограничения копий описаны в README.

## Дополнительно: сборка и проверки

Для просмотра готовой сборки:

```powershell
npm.cmd run build
npm.cmd run preview
```

Откройте **http://127.0.0.1:4173** или другой адрес из терминала. Preview также запускает API. Не открывайте `dist/index.html` напрямую: приложению нужен работающий backend. Остановка — **Ctrl+C**.

```powershell
npm.cmd test
npm.cmd run test:e2e
```

Браузерные проверки требуют установленного Google Chrome и mock-режима (`AI_MODE=mock`). Они сами запускают сервер на порту 5173 либо используют уже работающий. Подробнее об устройстве проекта и ограничениях — в [README.md](README.md).
